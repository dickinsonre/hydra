# Changelog

## [18.0.0](https://github.com/dickinsonre/hydra/compare/v17.0.1...v18.0.0) (2026-11-08)


### ⚠ BREAKING CHANGES

* **interop-swmm:** `DiagnosticKind` gains `InletNamesNoMapRow`.
* **uds:** `NetworkQuality::update` takes the surface's per-vertex lateral share, and `Router::is_coupled` is removed.
* **uds:** `ParcelOutlet` and `MassSource` each gain a variant and `MassSource::COUNT` is six; `CouplingRow`, `LedgerRow` and `NetworkQuality` each gain a public field; `LedgerRow`'s array widens to twelve terms. The checkpoint format moves to 6, and the overland results sidecar to 3, whose reader still serves versions 1 and 2 so results already written stay readable. The three GUI edits here are the match arms that keep it compiling; splitting them out would need a red intermediate, so the release-track signal reads as breaking for the GUI when only the library's API changed.
* **common,wds,uds:** `produce_report_block` takes the run's diagnostics, and `SessionWarning::element` is now `element_id`. The CLI and GUI edits here are the mechanical call-site updates that keeps them compiling; splitting them out would need a red intermediate, so the release-track signal reads as breaking for all three tracks when only the library's API changed.
* **wds:** pin a link that will not stop changing status
* **engines,wds:** one phase, now that a run has one pass
* **wds:** hold one instant, not the whole run
* **wds:** advance quality within the hydraulic step, not in a second pass
* **wds:** remove the session's unread result-range fold
* Simulation::open and the open_with_* family, write_report/write_out, the interface-file writers, supply_* by text, and begin_*_results moved to hydra::swmm::session as free functions; OpenError::Parse now lives on the dialect's OpenError, wrapping the engine's build refusals.
* **uds:** mesh models that previously refused with "specified and not yet served" now open and run; OpenError::Overland carries attach defects instead of the serving refusal.
* **wds:** combine rule premises as the predecessor's accumulator does
* **uds:** ValidationKind::InterfaceFileNotWritten is removed. It reported a declared interface file that would not be written, and every format §14.8 declares is now served, so nothing can emit it.
* **common:** common::ENGINES no longer contains the och descriptor, and engine_by_key("och") returns UnknownEngineError.
* **common,engine:** `AttributeDescriptor::references` is a `Vec<String>` rather than an `Option<String>`, and serialises as an array. A consumer reading it as a string reads one kind where there may be several.
